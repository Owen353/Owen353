## 🚀 Featured projects

### [vehicle-rental-manager](https://github.com/Owen353/vehicle-rental-manager)
**Java · Spring Boot 3.3 · Spring Data JPA · React 18 · Vite · JUnit 5 · GitHub Actions**

Full-stack fleet management system.
- REST API enforcing rental business rules: JPQL interval-overlap detection to block double bookings, maintenance-status gating, and billing that re-prices on early return
- Layered design with record DTOs and RFC 7807 error responses
- 15 JUnit 5 / Mockito / MockMvc tests; CI runs tests and the front-end build on every push

### [EPL-Transfer-analysis](https://github.com/Owen353/EPL-Transfer-analysis)
**Python · NumPy · pandas**

Does spending in the transfer market buy results in the Premier League?
- Data pipeline merging Transfermarkt fees with match results for 300 club-seasons (2010–2025)
- Linear and logistic regression implemented from scratch in NumPy
- Finding: transfer spending explains only ~24% of variance in points; last season's points (test R² 0.34) beat every spending measure on held-out 2022–25 seasons

### [Vehicle-Management-System](https://github.com/Owen353/Vehicle-Management-System)
**MySQL · Node.js · Express**

Truck rental management system built in a 4-person team for a databases course.
- Normalized 14-table MySQL schema covering branches, vehicles, clients, reservations and billing
- SQL triggers and integrity constraints enforcing availability, rental periods and pricing
- Node.js backend reaching the university-hosted database through an automated SSH tunnel, with connection pooling and parameterized queries
